# Desafio - Scratch Nível 1
### Ativo entre: 17/11/2024 e 29/11/2024

## 💡 Ideia:

Cria o teu personagem e o teu cenário para experimentar roupa.

## ✅ Regras:

1. Deve existir um(a) modelo para trocar de roupa.
2. Devem existir pelo menos 3 peças de roupa para serem trocadas e experimentadas no modelo.
3. Deve ser criada uma maneira de trocar a roupa.
4. Deve haver uma maneira de mudar o cenário para poder tirar as melhores fotos ao teu modelo. :)

Podes inventar os extras que quiseres, por exemplo, adicionar sons ou efeitos visuais de cada vez que a roupa é trocada.

## 🧩 Blocos a serem usados

Para este projeto, deves usar obrigatoriamente, mas não só:

- Blocos de cenário da categoria “Aparência” (Looks).
- Blocos de traje da categoria “Aparência” (Looks).

Deves ser tu a descobrir para que é que estes blocos serão úteis no teu projeto e usá-los da forma que achas que funcionará melhor.
