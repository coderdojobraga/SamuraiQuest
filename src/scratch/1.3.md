# Desafio - Scratch Nível 3
### Ativo entre: 17/11/2024 e 29/11/2024

## 💡 Ideia:

Cria um estabelecimento onde clientes podem fazer compras. Pode ser qualquer tipo de negócio, usa a tua criatividade!

## ✅ Regras:

1. Devem existir pelo menos 3 produtos diferentes para serem comprados.
2. Devem existir clientes que aparecem para comprar.
3. Deves ser capaz de criar uma forma de lhes responder aos pedidos, e quando recebem o que pediram, deixam o dinheiro e vão-se embora.

Podes inventar os extras que quiseres, por exemplo contar o dinheiro que vais recebendo pelas compras.

## 🧩 Blocos a serem usados

Para este projeto, deves usar obrigatoriamente, mas não só:

- Clones da Categoria "Controlo" (Control).
- Variáveis da Categoria "Variáveis" (Variables).
- Listas da Categoria "Variáveis" (Variables).

Deves ser tu a descobrir para que é que estes blocos serão úteis no teu projeto e usá-los da forma que achas que funcionará melhor.
