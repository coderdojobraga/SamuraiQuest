# Desafio - Scratch Nível 2
### Ativo entre: 17/11/2024 e 29/11/2024

## 💡 Ideia:

Cria um sistema de estradas onde existem semáforos para controlar o trânsito. Usa a tua criatividade!

## ✅ Regras:

1. Devem existir 2 estradas a cruzarem-se.
2. Deve existir 1 carro a passar em cada estrada.
3. Deve existir 1 semáforo para cada estrada, e estes devem mudar as suas cores conforme o tempo.
4. Os carros devem parar quando o semáforo da estrada onde passam estiver vermelho, e andar quando estiver verde.

Podes inventar os extras que quiseres, por exemplo adicionar um botão que permita mudar imediatamente a cor dos semáforos.

## 🧩 Blocos a serem usados

Para este projeto, deves usar obrigatoriamente, mas não só:

- Mensagens da Categoria “Eventos”.
- Cronómetro da Categoria “Sensores”, se decidires usá-los para contar o tempo.
    - Alternativamente, os “Espera” da Categoria “Controlo”.

Deves ser tu a descobrir para que é que estes blocos serão úteis no teu projeto e usá-los da forma que achas que funcionará melhor.
