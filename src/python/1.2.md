# Desafio - Python Nível 2
### Ativo entre: 17/11/2024 e 29/11/2024

## 💡 Ideia:

Criar um sistema simples para gerir uma **biblioteca** com livros e utilizadores. O sistema deverá permitir adicionar, remover e listar livros, bem como permitir que os utilizadores façam **empréstimos** de livros.

## ✅ Regras:

1. **Livros**: Cada livro tem título, autor e se está disponível ou emprestado.
2. **Utilizadores**: Cada utilizador tem nome e um número máximo de livros que pode ter em **empréstimo**.
3. **Funções**:
    - Adicionar livros à biblioteca.
    - Remover livros da biblioteca.
    - Listar todos os livros.
    - Verificar a disponibilidade dos livros.
    - Empréstimos de livros para os utilizadores.
4. O sistema deve permitir aos utilizadores:
    - Pedir livros emprestados, caso estejam disponíveis.
    - Devolver livros.
    - Ver a lista de livros emprestados.
5. Estas operações devem estar disponíveis através de um menu.

## 🧩 Dicas de Resolução

- **Listas**: Para armazenar os livros e os utilizadores.
- **Dicionários**: Para armazenar informações dos livros e utilizadores de forma mais eficiente.
- **Funções**: Para realizar as operações principais, como adicionar, remover livros, e realizar empréstimos.
- **Ciclos e Condicionais**: Para controlar o fluxo das operações.
